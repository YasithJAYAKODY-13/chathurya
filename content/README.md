# Site content

Everything shown on the site lives here, one folder per tab.

| Folder | Tab on the site |
|---|---|
| `singing/` | Singing (songs, music videos) |
| `concerts-and-events/` | Concerts and events |
| `television/` | Television (TV performances, TV podcasts) |
| `the-voice/` | The Voice Sri Lanka (Blind Auditions, Best of the Week, Battles, Knockouts, Live Shows) |
| `film/` | Film |
| `education/` | Education (degree, research, why it matters) |
| `press/` | Press and media features (shown on the home page) |
| `gallery/` | Photos not tied to one event |
| `inbox/` | New material received but not yet published |

Each folder has `items.json` (one entry per performance) and `images/` (photos and posters for that folder).

Image names: `YYYY-MM-DD-short-name-N.webp`, for example `2026-10-17-handawaka-anuradhapura-1.webp`.
Each entry's `id` matches its image names, so a performance's photos are easy to find.
